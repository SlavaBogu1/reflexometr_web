CR-UI-29 mockup — admin Library icon-button consistency

Archive/Restore/Export/View/Delete converted to uniform small icon buttons with title (native tooltip) + aria-label instead of full-text labels, and all four grouped together in the Actions column (the Versions column now shows only the version chip itself — the action buttons no longer live split across two columns). Reuses the .manage-results-toggle-btn pattern already proven in stats-page.js — same size, border, hover treatment; Delete keeps a distinct danger color (border + hover-fill) rather than a differently-shaped button. Archive uses a lidded-box glyph, intentionally distinct from Delete's trash-can glyph, so the two destructive-looking but very different actions (soft-archive vs. permanent delete) are never visually confusable.

Icon detail (hover/tooltip state)

All buttons same size (1.8rem square), bordered, hover highlights to accent color. Delete additionally uses danger coloring (border + hover-fill) to preserve its distinct destructive weight. Each button's title attribute shows as a native browser tooltip on hover (not rendered in this static mockup, but try it after implementation) — this is what replaces the visible text label and what makes the design i18n-friendly (one glyph, any language).
