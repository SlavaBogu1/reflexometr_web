What changed vs. the first draft (rejected — didn't scale):

  • Every tag renders as its own clickable pill in a wrapping grid, not a fixed checkbox list — the container scrolls internally (max-height + overflow-y: auto) once there are enough tags to overflow, so the form itself never grows unbounded regardless of tag count.
  • Clicking a pill toggles it selected/unselected (bright accent fill = selected, matching .chip.category-highlight's bright treatment from CR-UI-25 — muted/outlined = unselected).
  • "Add tag" still available below the grid for creating a brand-new tag not yet in the catalog.
  • This pattern has no existing precedent elsewhere in the project, but reuses the same pill/chip visual language (.chip-style rounded pill, accent-vs-muted color states) already established by .chip.version/.chip.category-highlight on browse.html.
