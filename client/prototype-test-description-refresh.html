Simple Visual Reaction Time

Test Description

A circle starts green. After a short, random delay it turns red — react as fast as you can using your configured input.

  • Watch the circle. It starts green (wait).
  • The moment it turns red, respond immediately with your configured key/button/click.
  • Responding before the color changes voids that trial — it will simply run again.

Test results analysis

A single run is a snapshot; run it regularly (e.g. daily) to see a meaningful trend, since day-to-day reaction time naturally varies.

Simple visual reaction time is one of the most-studied measures in reaction research — typical adult values fall in a fairly narrow band, making it a useful, low-effort baseline to track over time.
